# Memento - AI 여행 기념품 생성 서비스

## 프로젝트 개요
- **해커톤**: 10X-THON
- **컨셉**: AI가 여행 사진을 예술 작품으로 변환하는 기념품 생성 서비스
- **핵심 가치**: "모든 여행이 작품이 되는 경험"

## 기술 스택
- **Backend**: Spring Boot 3.5.7 + Kotlin 1.9.25
- **Language**: Java 21
- **Build**: Gradle (Kotlin DSL)
- **AI**: AWS Bedrock (예정)

## 핵심 아이디어

### 서비스 전환점
- **기존**: 리뷰 사진 → 기념품 (문제: 낮은 품질, 심리적 반발)
- **개선**: 야놀자 고품질 상품 사진 → 기본 기념품 제공 + 선택적 개인 사진 추가

### 차별화 포인트
1. **프로 사진 베이스** - 실패 없는 고품질 보장
2. **빠른 생성** - 30초 내 완성
3. **개인화** - 원하면 개인 사진 추가 가능
4. **부담 없음** - 무료 디지털 파일 제공

### AI 맞춤 제안 (사진 장수별)
- **0장**: 미니멀 아트 포스터
- **1장**: 영화 포스터 스타일
- **2-3장**: 매거진 스타일
- **5장+**: 포토북 형태
