# 서비스 컨셉

## 🎯 아이디어 배경

### 초기 아이디어의 문제점
처음에는 "리뷰 사진으로 기념품 제작"을 생각했지만:
- 리뷰용 사진은 대충 찍어서 **품질이 낮음**
- 리뷰 작성 자체가 **귀찮은 일**
- 공개하고 싶지 않은 **개인 사진들**
- "리뷰 쓰면 기념품 준다" → **심리적 반발감**

### 발상의 전환
→ 야놀자가 이미 가진 **고품질 상품 사진**을 활용하자!
→ 여기에 고객이 원한다면 **개인 사진을 추가**
→ AI가 둘을 멋지게 **합성해서 작품**으로 만들자!

## 🎨 서비스 컨셉

"프로가 찍은 여행지 사진 + 내 사진 = AI가 만든 예술 작품"

- **기본 제공**: 제주 바다, 호텔 전경 등 프로 사진
- **선택 추가**: 고객이 원하면 개인 사진 1-3장
- **AI 마법**: 3초 만에 잡지 표지 같은 작품 완성

## 👤 AI 똑똑한 제안 시나리오

### 사진 0장 - 부담 없이 시작
- **고객**: "사진 올리기 귀찮아..."
- **AI**: "괜찮아요! 제주 절경 사진으로 멋진 포스터 만들어드릴게요"
- **결과**: 일몰 배경의 미니멀 아트 포스터

### 사진 1장 - 주인공은 나!
- **고객**: 커플 셀카 1장 업로드
- **AI 분석**: "아, 로맨틱한 여행이네요!"
- **AI 제안**: "두 분을 주인공으로 한 영화 포스터 어때요?"
- **결과**: '제주에서 생긴 일' 영화 포스터 (커플이 주인공)

### 사진 2-3장 - 스토리가 있는 여행
- **고객**: 가족사진 2장 + 맛집 사진 1장
- **AI 분석**: "가족 여행 + 미식 여행이시군요!"
- **AI 제안**: "여행 매거진 스타일로 스토리를 담아볼까요?"
- **결과**: 'FAMILY TRAVELER' 잡지 표지 + 내지 구성

### 사진 5장 이상 - 완벽한 추억 보관
- **고객**: 다양한 사진 여러 장
- **AI 분석**: "추억이 정말 많으시네요!"
- **AI 제안**: "12페이지 포토북으로 시간순 스토리텔링 어떠세요?"
- **결과**: 하루하루 담긴 여행 포토북

## 🤖 AI 사진 성격별 매칭

### 인물 사진 → 감성 포커스
- **배경**: 석양, 노을 등 감성적인 상품 사진 선택
- **스타일**: 따뜻한 톤, 영화 포스터 스타일
- **문구**: "우리들의 특별한 순간"

### 풍경 사진 → 자연 강조
- **배경**: 와이드한 파노라마 상품 사진 선택
- **스타일**: 내셔널지오그래픽 스타일
- **문구**: "자연이 선물한 감동"

### 음식 사진 → 미식 여행
- **배경**: 현지 시장, 레스토랑 상품 사진
- **스타일**: 요리 매거진 스타일
- **문구**: "맛있는 제주 이야기"

### 활동 사진 → 다이나믹
- **배경**: 액티비티, 체험 관련 상품 사진
- **스타일**: 스포츠 매거진 스타일
- **문구**: "도전과 모험의 기록"

## 💝 고객 여정별 접근

### 1️⃣ 예약 완료 시
"여행 전부터 설렘을 드려요"
→ 상품 사진으로 미리보기 제공

### 2️⃣ 여행 중
"지금 이 순간을 작품으로"
→ 방금 찍은 사진으로 즉시 제작

### 3️⃣ 여행 후
"추억을 영원히 간직하세요"
→ 베스트 사진으로 최종 기념품

## ✨ 차별화 포인트

### 1. 실패가 없다
- 프로 사진이 베이스라 품질 보장
- 사진 없어도 만들 수 있음

### 2. 쉽고 빠르다
- 30초 만에 완성 (타사는 2시간)
- AI가 알아서 다 해줌

### 3. 개인화되어 있다
- 내 사진이 들어가면 세상에 단 하나
- AI가 여행 스타일을 분석해 맞춤 제작

### 4. 부담이 없다
- 무료로 디지털 파일 제공
- 마음에 들면 실물 제작

## 📈 기대 효과

- **차별화**: "AI가 추억을 작품으로" - 업계 최초
- **만족도**: 특별한 기념품으로 여행 만족도 상승
- **바이럴**: SNS 공유 "야놀자에서 이런 것까지!"
- **재방문**: 다음 여행도 기념품 받으려고 야놀자 선택

## 🎯 핵심 전략

**"주면서 요구"가 아닌 "주고 나서 선택권"**
- ❌ "리뷰 쓰면 기념품 줄게" → 반발심리
- ✅ "기념품 줄게, 원하면 네 사진도 넣을 수 있어" → 자발성

**단계적 접근**
- 초기: 심리적 거부감 없이 기념품 제공
- 중기: 사진 추가 옵션으로 참여 유도
- 후기: 자연스러운 리뷰 연결
