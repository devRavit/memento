## 개발 환경

### 네트워크
- **사내망**: `yanolja-group_Wifi` (야놀자, 놀유니버스, 야놀자 넥스트)
- **게스트망**: `yanolja-group_Guest` (산하정보기술, 데이블, 야놀자 리서치 등)
- **비밀번호**: `Ya@nol2!` (대소문자 구분)

### 클라우드 환경
**AWS & GCP 샌드박스 제공**
- IAM 기반 Admin 권한 (Root 계정 사용 안 함)
- 10X 타워 내 VPN/MDM 등록 기기에서만 접속 가능
- AWS Bedrock, Lambda, S3, ECS, RDS 등 전 서비스 활성화
- 샌드박스 환경은 해커톤 종료 후 30일간 유지

**⚠️ 샌드박스 외부 환경(홈서버, 개인 NAS, 외부 클라우드)은 접근 차단**

### 결과물 제출 방법
1. **데모 영상 제출** - 로컬 파일, Google Drive, YouTube 링크 등
2. **로컬 실행 시연** - localhost:port 기반
3. **샌드박스 기반 배포 URL**

**제출 마감**: 각 심사 시작 30분 전까지
